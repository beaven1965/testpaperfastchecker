# TestPaper FastChecker — 90-second video script

Film on your phone, vertical or horizontal. Voice in Taglish is fine. Show hands and papers, not your face if you prefer.

| Time | What we see | What we hear |
|---|---|---|
| 0–8s | A tall pile of test papers on a table at night. A red ballpen. | "Linggo ng gabi. Isang daan at limampung papel. Kilala mo 'to, 'di ba, ma'am, sir?" |
| 8–20s | Hand tallying item analysis on a pad: 1 ||||, 2 ||, 3 |||| … | "Hindi lang pag-check. Pati item analysis, bibilangin mo isa-isa, item 1 hanggang 50. Tapos MPS pa." |
| 20–30s | Phone screen: TestPaper FastChecker home, tap **New test**, tap A B C D quickly. | "Ito ang TestPaper FastChecker. Gawa ng isang senior teacher, para sa mga teacher. Una, i-type ang answer key. Isang minuto lang." |
| 30–40s | Printer printing sheets. Close-up: learner's name already printed. | "I-print ang answer sheets. Nakasulat na ang pangalan ng bawat estudyante. Walang mapagpapalit na pangalan." |
| 40–58s | Phone takes a photo of a shaded sheet. Score appears with green and red circles. Tap **Save**. Next paper. Repeat 3 times fast. | "Kunan ng litrato ang bawat papel. Lumalabas agad ang score. Save, next. Labinlimang segundo bawat papel." |
| 58–72s | Results screen: big MPS, item analysis table, "Reteach these items" chips. Tap Excel. | "Pagkatapos, nandiyan na ang MPS, ang item analysis, at kung aling items ang dapat ituro ulit. May Excel file pa para sa class record." |
| 72–82s | Teacher closes the laptop, smiles, goes to family. | "Ang dating dalawa't kalahating oras, mga labindalawang minuto na lang." |
| 82–90s | Screen: testpaperfastchecker.netlify.app · "100 papers FREE" | "Subukan nang libre ang unang isang daang papel. Pumunta sa test paper fast checker dot netlify dot app." |

Tips: keep each shot short, add big captions (many people watch muted), and end on the web address for 3 seconds.
